A mark that is the thing it names.

Construction

Three readings, one glyph.

Every element is load-bearing. Nothing was added because the composition looked empty.

A lowercase d

The product's own initial. The mark is the name, not an ornament bolted to it.

node → pipe → ring

The real topology: an MCP client, a local named pipe, and the running scene it reaches into. Left to right is the request path.

Two figures, unequal

Didi and Gogo. The repository's own GOGO_DESIGN.md puts it exactly: Didi waits; Gogo is the one who actually shows up.

Scale

Legible at sixteen pixels.

The bowl's counter stays open and the node stays detached all the way down. Rendered here at true 1:1: these are the actual exported PNGs, not scaled previews.

Below 20 px the compact weight takes over: stroke 12 and a larger node, so the form survives rasterisation instead of filling in. The favicon on this page is that weight.

Lockup

The stutter, and the fix.

Because the mark is a lowercase d, setting it beside the wordmark reads as “d didi.” This is the one real trap in the system, so the identity resolves it structurally rather than asking anyone to remember a rule.

Colour

Inherited, not invented.

Both brand colours already sit in Didi's own README badges. The mark is the bridge between exactly those two things, so the palette was there before the logo was.

In the brand signature, MCP violet enters at the node and Godot blue exits at the final i. Two coloured dots carry the whole idea while the letterforms stay neutral. A gradient never runs across the wordmark: below roughly 200 px it flattens to a single hue and fights legibility.

Applications

Where it lands.

Didi — godot-mcp-native

The favicon uses the compact weight. At 16 px the node still separates cleanly from the bowl.

Inside the Godot editor the same three sources ship with the addon, rasterised at the editor's own scale with the theme's font colour substituted for currentColor. The main screen tab icon is 16 px, which is why the compact cut earns its place.

Rejected

What the mark deliberately is not.

Four directions were built and discarded. Each failed for a reason worth recording, so nobody rebuilds them next year.

Robot head

Godot's own mark, and a trademark of the Godot Foundation. Borrowing it would make Didi look like a fork of the engine rather than a bridge to it.

Theatre masks

The obvious Waiting for Godot nod, and wrong on the merits: a mask connotes pretense. Didi's stated value is being explicit about what it can actually execute; it ships implemented: false rather than pretend.

Scene-tree diagram

The Beckett-tree and SceneTree pun is real, but drawn honestly it becomes the generic org-chart icon, and it dissolves into noise below 32 px.

Circuit board, brain, globe

Category clichés. They say “technology” and nothing whatsoever about this technology.

Files

Manifest.

Thirteen SVG sources and forty-nine PNG exports, living at docs/brand/ in the repository and served from this site. Every asset derives from the constants at the top of build.py; nothing is hand-placed, so changing one stroke weight re-derives the entire system. The banners and social preview ship as PNG deliberately: their SVG sources set text in a system font, which GitHub's SVG sanitiser does not render reliably.
